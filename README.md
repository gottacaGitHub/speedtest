# speedtest.py

Консольный скрипт: последовательно скачивает указанный URL N раз,
дожидается полного ответа на каждый запрос и печатает скорость скачивания.

## Установка

    pip install -r requirements.txt

## Запуск

    python speedtest.py https://example.com/heavy.jpg

Флаги:

| Флаг | Описание |
|---|---|
| `-n, --attempts N` | число запросов, по умолчанию 10 |
| `--timeout S` | таймаут одного запроса в секундах, по умолчанию 60 |
| `--fresh-connection` | новое TCP/TLS-соединение на каждый запрос |
| `--cache-bust` / `--no-cache-bust` | добавлять `?nocache=<uuid>` и no-cache заголовки (по умолчанию вкл.) |

## Методика

- **N запросов последовательно**, все N идут в статистику (прогрева нет).
- **Время запроса** — полное: от отправки до полного чтения тела
  (`time.perf_counter()` вокруг `stream()` + `iter_raw()`, замер до выхода из `with`).
- **Объём скачанных данных** — **application bytes** на проводе: тело ответа
  после декодирования `Transfer-Encoding: chunked`, но **до** декодирования
  `Content-Encoding` (gzip/br/zstd). Это то, что реально пришло по сети
  в виде тела HTTP-ответа. **Не** учитываются заголовки TLS/TCP и HTTP —
  фактическая нагрузка на канал на ~2–5% выше из-за TLS/TCP-оверхеда.
- **Среднее время запроса** — арифметическое по N замерам.
  Дополнительно печатаются медиана и стандартное отклонение: медиана устойчива
  к выбросам, σ показывает стабильность канала.
- **Скорость скачивания** — `суммарный объём / суммарное время`.
- По умолчанию используется **keep-alive** (одно TCP-соединение на все запросы).
  `--fresh-connection` даёт «холодный» замер: handshake входит в каждый запрос.
- **Cache-bust** (`?nocache=<uuid>` + `Cache-Control: no-cache` / `Pragma: no-cache`)
  включён по умолчанию — иначе CDN/сервер могут отдать один и тот же файл из кэша,
  и замер будет врать.

## Единицы

- **MiB/s** — мебибайты в секунду (1 MiB = 1 048 576 байт) — основная единица.
- **Mbit/s** — мегабиты в секунду (1 Mbit = 1 000 000 бит) — дополнительная.

## Ограничения

- Один поток, один URL; upload / ping / jitter не измеряются.
- Cache-bust не гарантирует обход кэша: сервер/CDN могут игнорировать
  `Cache-Control` и `?nocache`. Для честного замера используйте заведомо
  некэшируемый URL.
- При редиректе на другой URL параметр `nocache` может потеряться.
- Ошибка любого из N запросов (таймаут, 4xx/5xx, обрыв, битый URL) → немедленный
  выход с кодом 1, без ретраев и без частичной статистики.
- `--fresh-connection` с HTTP/2: каждый запрос — отдельный `httpx.Client`
  (и, значит, отдельное соединение).

## Тестируемость

Транспорт вынесен за `Fetcher` Protocol, оркестрация — в `SpeedMeter`,
вывод — в `Reporter`. Для тестов достаточно `FakeFetcher`,
возвращающего заданные `Attempt`, без сети. `ConsoleReporter` принимает
`TextIO` — удобно проверять через `io.StringIO`.
